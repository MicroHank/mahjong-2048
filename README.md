# 3D 疊疊樂麻將 2048 (Mahjong 2048 3D)

結合 **2048 合併機制** 與 **3D 雙子疊疊樂 / 空間消消樂** 的現代 Web 3D 益智遊戲。

![Game Preview](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?w=1200&auto=format&fit=crop&q=80)

---

## 🎮 遊戲核心特色

1. **左右兩堆雙陣地佈局 (Dual-Heap Architecture)**：
   - 關卡規模擴大為壯觀的**左右兩大獨立方塊陣地**。
   - 支援跨陣地尋找相同數字進行跨空合併，充滿空間縱深與探索感。

2. **直覺休閒頂部判定 (Casual Rule)**：
   - **頂部判定**：只要方塊正上方沒有其他方塊壓著，即可隨心所欲自由選取！
   - **視覺智能提示**：可選取方塊色彩鮮豔並微發光；被遮蔽方塊呈現暗色半透明與 🔒 鎖定圖示。

3. **顯著選取與能量光軌合併特效 (Glowing Beacon & Energy Trajectory)**：
   - **浮空立體光標 (3D Selection Beacon)**：點選方塊時，方塊明顯向上浮起，上方伴隨旋轉金色水晶與賽博光環，一眼即識。
   - **拋物線能量光軌 (3D Trajectory Route Line)**：兩相同方塊合併時，在 3D 空間中劃出青藍色能量拋物光弧，方塊沿著光軌高速旋轉滑入！
   - **衝擊波震盪 (Shockwave Impact)**：合併碰撞時於平面擴散出衝擊波光環與彩色星芒粒子，數值翻倍彈跳，爽快感倍增！
   - **終極 2048 光爆**：合併達到 **2048** 時，引發全屏光爆煙火並直接自盤面消除！

4. **5 大宏偉立體雙子關卡**：
   - 🔺 **第 1 關：雙子階梯金字塔**（左右並列雙金字塔，層次分明）
   - 🗼 **第 2 關：雙塔天梯要塞**（左翼與右翼高塔，消除底層觸發壯觀重力崩塌）
   - 🧊 **第 3 關：雙生萬花魔術方塊**（左右實心立方體，由外向內剝除外殼）
   - 🏯 **第 4 關：東西雙城要塞**（東西對峙的雙城要塞與中樞天橋）
   - 🌀 **第 5 關：雙螺旋星雲聖殿**（左右呼應的雙螺旋旋轉天階）

5. **豐富的輔助救援系統**：
   - ↩️ **上一步 (Undo)**：隨時悔棋回復盤面與分數。
   - 💡 **提示 (Hint)**：以青藍色脈衝光高亮盤面可合併的方塊對。
   - 🔀 **智慧洗牌 (Smart Shuffle)**：保持立體結構不變，自動在未遮蔽位置產生可選配對，絕不卡死！
   - 📐 **快速視角切換**：3D 等角、頂視鳥瞰、正視與一鍵鏡頭重置。
