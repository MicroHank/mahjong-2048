# 3D 疊疊樂麻將 2048 (Mahjong 2048 3D)

結合 **2048 合併機制** 與 **3D 疊疊樂 / 麻將消消樂 (Mahjong Solitaire)** 的現代 Web 3D 益智遊戲。

## 🎮 遊戲核心特色

1. **空間遮蔽與自由度判定**：
   - **頂部判定**：正上方若壓著其他方塊，即被灰色鎖定遮蔽，無法點擊。
   - **雙重自由度模式**（可隨時在遊戲頂部切換）：
     - 🍃 **直覺休閒模式 (Mode A)**：只要頂部無遮蔽即可選取。
     - 🀄 **立體麻將模式 (Mode B)**：頂部無遮蔽，且水平四個方向（前、後、左、右）中至少有邊緣未被緊貼，才算自由方塊。
   - **視覺智能提示**：可選取方塊色彩鮮豔並微發光；被遮蔽方塊呈現暗色半透明與鎖定圖示。

2. **合併與重力連鎖機制 (Gravity & Cascade)**：
   - 點選第一個方塊（金色發光微浮起），再點選第二個相同數字方塊即可合併。
   - 拋物線飛行滑動融合，數字翻倍（如 $4 + 4 \to 8$），伴隨彈跳震動與星光粒子。
   - **重力連鎖下墜**：下方方塊消失後，原本壓在上面的方塊自動下墜填補空缺，並解鎖底層被遮蔽的方塊！
   - **終極 2048 光爆**：合併達到 **2048** 時，引發全屏光爆煙火並直接消除，獲得巨額分數！

3. **5 大立體幾何關卡**：
   - 🔺 **第 1 關：階梯金字塔**（頂層少、底層多，層次分明）
   - 🗼 **第 2 關：雙子懸空塔**（消除底層柱腳會觸發大幅垂直下墜連鎖）
   - 🧊 **第 3 關：萬花魔術方塊**（實心 3x3x3 方體，由外向內「剝洋蔥」）
   - 🏯 **第 4 關：東方長城要塞**（外圍城牆與中央主塔）
   - 🌀 **第 5 關：天空螺旋神殿**（高度落差極大的旋轉騰空石階）

4. **豐富的輔助救援系統**：
   - ↩️ **上一步 (Undo)**：隨時悔棋回復盤面與分數。
   - 💡 **提示 (Hint)**：以青藍色脈衝光高亮盤面可合併的方塊對。
   - 🔀 **洗牌 (Shuffle)**：保持立體結構不變，打亂現存方塊數字分佈。
   - 📐 **快速視角切換**：3D 等角、頂視鳥瞰、正視與一鍵鏡頭重置。

5. **視聽體驗 (WOW Factor)**：
   - 賽博禪風深色玻璃擬態 UI（Glassmorphism）。
   - 內建 **Web Audio API** 程式音效（零外部素材相依，即開即響，升階音階、重力敲擊音、2048 勝利號角）。
   - 完整支援 PC（滑鼠旋轉/縮放）與手機觸控（單指旋轉/雙指縮放）。
